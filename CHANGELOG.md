# Changelog

This changelog records repository changes. It does not describe official Airbnb product functionality. Dates should be added to release headings when a release is formally published.

## Unreleased

### Added
- Expanded the documentation index and added detailed guides for HTML/CSS standards, browser testing, asset and content management, SEO metadata, privacy, quality assurance, release management, and security practices.
- Added detailed guidance for static-site installation, architecture, development, accessibility, API boundaries, database boundaries, deployment, FAQ, and troubleshooting.
- Expanded contribution, support, security, and community conduct policies.

### Changed
- Clarified that the repository is an independent educational static interface and not an official Airbnb product.
- Improved documentation around sample listing data, non-functional controls, and the absence of live search, booking, availability, accounts, API, database, and payment features.
- Added explicit review expectations for media licensing, privacy, keyboard access, responsive behavior, and deployment verification.
- Updated repository governance and automated validation guidance.

### Fixed
- Removed duplicated responsive CSS refinement blocks.
- Improved repository guidance to distinguish static checks from real browser tests and production deployment.
- Clarified that the README timestamp workflow is maintenance automation and does not deploy the website.

### Known limitations
- Search, filters, favorites, profile controls, booking, accounts, payments, APIs, and database behavior are not implemented.
- Listing names, travel distances, dates, and prices are sample content.
- Asset presence in the repository does not establish permission for commercial reuse.
- CI checks file and reference integrity but does not provide full browser, accessibility, or security testing.

## Earlier repository maintenance

- Added project documentation and clarified static-demo scope.
- Added repository issue templates and pull request guidance.
- Added static-site validation and Dependabot configuration.
- Added contribution, security, support, code of conduct, changelog, roadmap, and citation metadata.
- Added repository ignore rules and removed tracked macOS metadata files.
