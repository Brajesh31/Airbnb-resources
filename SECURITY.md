# 🔐 Security Policy

## Project scope

This repository is a static HTML/CSS learning project. It currently has no backend, authentication, database, payment processing, user accounts, or API.

## Reporting a vulnerability

For a security concern involving this repository, contact the maintainer, Brajesh Kumar (`Brajesh31`), privately through GitHub. Include a concise description, affected file, impact, and sanitized reproduction steps.

Do not publish credentials, tokens, personal information, or exploit details in a public issue.

## Security expectations

- Never commit secrets, API keys, passwords, or private environment files.
- Do not add client-side collection of passwords, payment data, or sensitive personal information.
- Validate and constrain any future user-controlled input on the server.
- Keep third-party scripts and dependencies to a minimum and review them before use.
- Only use images, fonts, logos, and other assets when usage rights are clear.

A security review of this static repository does not establish that a future booking or marketplace application is secure.
