# 🗺️ Roadmap

This roadmap describes potential improvements to an educational static interface. Items are not commitments to build a real accommodation marketplace.

## Near term
- [x] Improve the page title and metadata.
- [x] Add responsive refinements for desktop, tablet and mobile.
- [x] Improve focus visibility and decorative image semantics.
- [x] Expand project documentation.
- [ ] Replace repeated sample listing data with a clearly maintained local data source, if useful.
- [ ] Add lightweight automated HTML and link validation.

## Future exploration
- [ ] Implement accessible category and filter interactions only if a clear demo requirement exists.
- [ ] Add documented browser smoke tests.
- [ ] Review all media and brand assets for reuse rights.
- [ ] Improve listing-card semantics and image descriptions.

## Out of scope for the current static project
- Real booking, account, payment, availability, host-management, or traveler-data workflows.
- Scraping or using Airbnb's private APIs.
- Implying affiliation with or endorsement by Airbnb.
