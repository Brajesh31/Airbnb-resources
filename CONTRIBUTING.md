# 🤝 Contributing

Thank you for helping improve this educational static interface.

## Scope

Contributions should improve semantic HTML, CSS quality, responsive behavior, accessibility, asset organization, documentation, or basic repository maintenance. Keep the project static unless an actual feature requires additional infrastructure.

## Before making changes

1. Read the relevant guide in [docs/README.md](docs/README.md).
2. Check existing issues and avoid duplicate work.
3. Keep changes focused and avoid unrelated formatting churn.
4. Preserve relative asset paths and use descriptive filenames.

## Validation

- Run a static server from the repository root.
- Check a narrow phone viewport, tablet, and desktop.
- Test keyboard navigation and visible focus.
- Check browser console and network failures.
- Verify local links and asset references.
- Confirm informative images have alternative text.

## Pull request checklist

- [ ] The reason for the change is clear.
- [ ] HTML and CSS remain understandable.
- [ ] Responsive behavior has been checked.
- [ ] Accessibility has been considered.
- [ ] No credentials, private data, tracking, or unlicensed media were added.
- [ ] Documentation is updated where behavior or setup changed.

Do not claim that static controls provide real booking, search, or payment functionality.
