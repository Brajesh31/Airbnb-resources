# Support and Project Help

## Before requesting help

Start with the [documentation index](docs/README.md). It covers setup, architecture, development, accessibility, browser testing, asset management, deployment, privacy, security, quality assurance, and troubleshooting.

For a local preview:

```bash
git clone https://github.com/Brajesh31/Airbnb-resources.git
cd Airbnb-resources
python -m http.server 8000
```

Open `http://localhost:8000`. No package installation or database setup is required.

## What to include in a support request

Provide the page, file, or workflow involved; browser and version; operating system; viewport dimensions and zoom; commit or branch; numbered reproduction steps; expected and actual behavior; sanitized Console or Network output; and a screenshot where useful.

Remove access tokens, passwords, personal information, and other sensitive values before sharing logs or screenshots.

## Where to ask

- Use GitHub issue templates for reproducible bugs, feature proposals, or documentation corrections.
- Read [CONTRIBUTING.md](CONTRIBUTING.md) before proposing code changes.
- Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not disclose vulnerabilities in public issues.

## Project limitations

This repository is a static educational UI. Search, filtering, login, profile management, favorites persistence, booking, availability, and payment are not implemented. Support requests should distinguish a defect in existing behavior from a proposal for new functionality.
