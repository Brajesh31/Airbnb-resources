# 🆘 Support

For questions about running or modifying this repository, first review the guides in [docs/README.md](docs/README.md).

When reporting a problem, include:

- Browser and operating system.
- Viewport dimensions and zoom level.
- The steps required to reproduce it.
- Expected and actual behavior.
- Relevant console or network errors.
- A screenshot with private information removed.

Use [CONTRIBUTING.md](CONTRIBUTING.md) for change proposals. Use [SECURITY.md](SECURITY.md) to report security concerns privately.

The current repository is a static UI exercise. Search, filtering, login, favorites, booking, and payment are not implemented.
