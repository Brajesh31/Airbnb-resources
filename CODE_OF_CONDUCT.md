# Code of Conduct

## Our commitment

The Airbnb-resources project welcomes constructive participation from people with different backgrounds, identities, and levels of experience. We aim to keep project spaces respectful, useful, and focused on improving the repository.

## Expected behavior

Participants are expected to be respectful, patient, and constructive; explain disagreements with evidence; give actionable feedback; accept good-faith corrections; respect privacy, licensing, and intellectual property; keep discussions relevant; and avoid assumptions about other contributors' knowledge or intent.

## Unacceptable behavior

The following conduct is not acceptable:
- harassment, discrimination, threats, or intimidation;
- personal attacks, insults, or deliberate humiliation;
- doxxing or disclosure of private information;
- publishing credentials or sensitive data;
- persistent disruption of issue or review discussions;
- knowingly submitting malicious code or deceptive project claims.

## Scope

This code applies to project spaces, including issues, pull requests, code reviews, and other communication directly associated with the repository.

## Reporting

Report conduct concerns privately to the maintainer, **Brajesh Kumar** (GitHub: [@Brajesh31](https://github.com/Brajesh31)), through GitHub. Include relevant context and links where possible. Do not publish private information in a public issue.

Reports will be reviewed as fairly and discreetly as possible. The maintainer may request clarification, remove inappropriate content, close discussions, or restrict participation when necessary to protect the project community.

## Maintainer responsibility

The maintainer is responsible for clarifying project expectations and applying this code consistently. Decisions should focus on observable behavior and the effect on project participation.

## Attribution

This is a project-specific code of conduct written for this repository.
