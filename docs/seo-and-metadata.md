# SEO and Page Metadata

## Scope
This document covers basic discoverability and metadata for a static educational page. It does not promise rankings, traffic, indexing, or affiliation with Airbnb. Describe the site accurately as an independent static interface exercise.

## Page title and description
The HTML title should be concise and specific. The description should summarize what visitors actually find: a static accommodation marketplace-style interface built with HTML and CSS. Do not imply live listings, verified prices, booking, or account services. Search engines may choose a different snippet.

## Headings and content
Use headings to organize content meaningfully. Do not use heading elements only to obtain a font size. Use CSS for visual presentation and semantic headings for document structure.

## Canonical URL
Add a canonical URL only when the public deployment URL is known and stable. Do not guess a hostname. If multiple URLs serve identical content, configure canonical behavior based on the actual hosting setup.

## Social previews
Open Graph metadata may improve link previews. Use an accurate title, description, authorized preview image, publicly reachable absolute image URL, and actual canonical page URL. Do not use brand imagery in a way that implies official ownership or endorsement.

## Robots and sitemap
Add robots or sitemap files only when the public URL is stable and there is a reason to guide crawlers. A sitemap should list canonical public URLs, not local development addresses or invented routes. A one-page static site may not need a sitemap.

## Performance and structured data
Fast loading, valid HTML, accessible content, and a clear page purpose are useful foundations. Avoid hidden keyword blocks, doorway pages, or misleading structured data. Do not add lodging, review, product, or booking schema unless the page genuinely represents those entities and the information is accurate and eligible.

## Trademark clarity
Metadata, title, social previews, and descriptions must not suggest that the page is operated by Airbnb. Include a clear disclaimer where appropriate.

## Validation checklist
- [ ] Title accurately describes the page.
- [ ] Description matches implemented functionality.
- [ ] Heading hierarchy is meaningful.
- [ ] No misleading brand or booking claims exist.
- [ ] Canonical URL is used only if confirmed.
- [ ] Social preview assets are authorized and public.
- [ ] Robots and sitemap files are accurate if present.
- [ ] Structured data does not invent listings or reviews.
