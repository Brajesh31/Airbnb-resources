# Installation and Local Preview

## Requirements
- A current web browser.
- Python 3, Node.js, or another static file server is optional but recommended.
- No package manager, framework, database, environment variables, or build step is required.

## Get the project
```bash
git clone https://github.com/Brajesh31/Airbnb-resources.git
cd Airbnb-resources
```

## Run a local server
```bash
python -m http.server 8000
```
Open `http://localhost:8000` and stop the server with Ctrl+C.

You can also open `index.html` directly, but serving the repository root more closely matches static hosting and makes path troubleshooting easier.
