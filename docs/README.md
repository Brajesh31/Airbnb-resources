# 📚 Documentation

This folder explains the current static interface, how to run it, how to change it, and what the project does not implement.

## Current scope

Airbnb-resources is a frontend reproduction and learning exercise built from HTML, CSS and local assets. It is not affiliated with Airbnb. It does not provide real search, accounts, booking, payments, listing management, APIs, or persistent favorites.

## Recommended workflow

1. Read [Installation](installation.md).
2. Review [Architecture](architecture.md).
3. Make a focused change.
4. Run the local checks described in [Development](development.md).
5. Review keyboard access and responsive layouts before publishing.

All sample property names, dates, distances, and prices are demonstration content. Do not interpret them as actual availability or market prices.
