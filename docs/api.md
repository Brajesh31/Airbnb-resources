# API

There is no API in the current project.

The page is served as static HTML, CSS, SVG, JPEG, and WebP files. It does not call Airbnb services or any external data provider. No API keys or runtime secrets are needed.

If a future version introduces an API, document endpoint, method, request and response schemas, authentication, validation, rate limits, error behavior, data retention, privacy, secret storage, testing, and versioning.

Never put private API credentials in client-side HTML, CSS, JavaScript, or committed environment files.
